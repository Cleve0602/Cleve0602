## 🚀 Academic Projects

### 🌡️ Arduino-Based ON/OFF Temperature Controller

Designed and implemented an ON/OFF temperature control system using MATLAB and Simulink. The control circuit was programmed and deployed to a physical temperature controller to maintain a specified temperature.

**Technologies:** Arduino, MATLAB, Simulink, Control Systems.

### 🚦 PLC-Based Four-Way Traffic Light with Pedestrian Crossing

Developed a four-way traffic light system with pedestrian crossing functionality using programmable logic controllers. The project incorporated timers, counters, sensors, and an HMI.

**Technologies:** Siemens TIA Portal, PLC, Ladder Logic, HMI.

### 🔢 Seven-Segment Display Using Logic Gates

Worked on a digital logic design project to implement a seven-segment display capable of displaying decimal digits from 0 to 9 using logic gates and a binary truth table.

**Technologies:** Digital Electronics, Logic Gates, Boolean Logic.

### 🔌 Smart Embedded Control Platform

Designed and implemented a microcontroller-based control system integrating ultrasonic and temperature sensors, output devices, and motor control. The system was simulated before being constructed and tested practically.

**Technologies:** Embedded Systems, Microcontrollers, Sensors, Electronics.
